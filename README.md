# 🚀 CYBER SURVIVOR: OVERDRIVE
### *الناجي السيبراني: السرعة القصوى*

A fast-paced, neon-drenched Cyberpunk Roguelite twin-stick arcade browser game built with pure modern web technologies (HTML5 Canvas 2D + Web Audio API Procedural Synthesizer).

Live browser game with zero external asset dependencies!

---

## 🌟 Key Features
- **Pure Procedural Audio Synth:** Real-time 80s synthwave music sequencer and sound effects generator via Web Audio API.
- **60+ FPS Object-Pooled Canvas Engine:** Additive neon bloom, shockwaves, damage floating text, screen shake, and camera follow.
- **Twin-Stick Action:** True manual mouse aiming with animated laser sight and left-click trigger.
- **Mobile & Tablet Ready:** Dual virtual joysticks (360 Movement stick + Aim & Fire stick) and fullscreen mode.
- **3 Unique Ships:** Vanguard-01, Phantom-X, and Colossus-MK4.
- **Roguelike Upgrades:** Twin Blaster, Homing Void Missiles, Orbital Sawblades, Tesla Chain Lightning, and Gravitational Singularities.
- **Boss Battles:** Wave 5 Cyber Hydra & Wave 10 Giga Titan.
- **Bilingual:** Full Arabic (العربية) and English support with one-click instant switch.
- **Core Hangar:** Permanent meta-progression shop saved locally via `localStorage`.

---

## 🕹️ Controls (التحكم)

### Desktop / PC
- **Movement (الحركة):** `WASD` or Arrow Keys.
- **Aim (التصويب):** Mouse pointer (Reticle + Laser Sight).
- **Fire (إطلاق النار):** `Left Mouse Button` (Click or Hold) / `J` key / `Enter`.
- **Dash (المراوغة السريعة):** `Space` / `Shift` / `Right Mouse Button`.
- **Ultimate Overdrive (القدرة القصوى):** `E` key.
- **Pause (إيقاف مؤقت):** `Esc` or `P`.

### Mobile / Touch
- **Left Virtual Stick (العصا اليسرى):** 360° Movement.
- **Right Virtual Stick (العصا اليمنى):** Aim & Fire in any direction.
- **⚡ Button:** Dash.
- **💥 Button:** Ultimate.
- **⛶ Button:** Fullscreen mode.

## 💻 How to Run Locally

Open `index.html` directly in any web browser, or serve with any static HTTP server:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

Then visit `http://localhost:8080`.
